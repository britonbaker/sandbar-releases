# Sandbar for Mac

A native menu-bar player for an Oasis Mini sand table, with a saved scene library and Up Next queue.

[Download the latest release](https://github.com/britonbaker/sandbar-releases/releases/latest)

Requires **Apple silicon and macOS 14 or later**. Download the ZIP, unzip it, move **Sandbar.app** to Applications, then open it. Releases are Developer ID signed and Apple notarized.

## Updates

Choose **Check for Updates…** in Sandbar’s panel menu. Sandbar uses Sparkle and offers automatic update checks; you choose when to install. Restarts wait for active drawings, transfers, queued handoffs and finish lights. No Sandbar account is required.

## Early preview

The controller currently targets the selected Oasis Mini and known firmware. Initial table connection and new-file delivery still need recipient setup verification. New-file delivery currently requires configured Ethernet/private Wi-Fi sharing and may require Mac administrator approval. The helper runtime is bundled; developer-tools Python is not required on the recipient Mac. Installing Sandbar does not automatically configure that connection.

This repository contains release downloads and the update feed. Project source, personal drawings and device state are not hosted here.
